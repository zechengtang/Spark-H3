MINIMAX-H3 · COMFYUI 插件

Spark-H3 安装包速览

让原生 MiniMax-H3 工作流使用 Spark 块稀疏注意力。

支持当前最新两个 ComfyUI 正式版本系列：0.38.x 和 0.39.x。适用 Linux 或 Windows x86_64、PyTorch CUDA 12.8/13.0、NVIDIA GeForce RTX 40 系（SM89），以及 GeForce RTX 50 系或 RTX PRO 5000/6000 Blackwell（SM120）。安装包不含模型权重。

选对安装包

GeForce RTX 40 系选 …sm89-cu130.zip

GeForce RTX 50 系或 RTX PRO 5000/6000 Blackwell 选 …sm120-cu128/130.zip

GPU 架构、系统与 torch.version.cuda 必须匹配。

包里有什么

Spark 节点、安装器、匹配的 CUDA 后端 wheel，以及 5 个示例工作流。

ComfyUI 本体、MiniMax-H3 权重和可选 LoRA 需另行准备。

三步安装

  1. 停止 ComfyUI，把对应 ZIP 解压到 ComfyUI/custom_nodes。
  2. 用启动 ComfyUI 的同一个 Python执行 ComfyUI-Spark-H3/install.py。
  3. 重启 ComfyUI，在工作流中连接：
    UNETLoader → MiniMax H3 Spark Attention → BasicGuider

内附样例

原生 20 步LightX2V 8 步Larryvrh 8 步DMAD 4 步LBH 双阶段

后四个样例可能需要额外 LoRA、转换权重或第三方节点；首次使用建议从“原生 20 步”开始。

平台说明：Windows CUDA 13.0 的 SM89 与 SM120 安装包均已完成实机验证；CUDA 12.8 正式包目前仅提供 Linux SM120。
