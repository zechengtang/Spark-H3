# 1003 下一步消融候选

基于 5s768p/50 prompts 与 10s768p/25 prompts 的完整生成、paired quality 和 VBench 复验，
下一步保留两个优先候选，并将第三项降级为速度导向备选：

1. `landmarks64`
   - 将每个 proxy 节点的 landmark 目标数量从 32 调整为 64，其余设置保持 baseline 不变。
   - 5s/50p：All PSNR `+0.057 dB`、SSIM `+0.0026`、LPIPS `-0.0034`，耗时 `+3.7%`。
   - 10s/25p：All PSNR `+0.487 dB`、SSIM `+0.0108`、LPIPS `-0.0111`，耗时 `+2.2%`；三项 paired 95% CI 均支持改善。

2. `q_reuses_k_layout`
   - 仅构造 K 侧 reblock 布局，Q 侧复用 K 侧在同一原始 video-token 索引空间中的最终置换；V 始终跟随 K。
   - 5s/50p：耗时 `-2.9%`，质量点估计接近中性至小幅改善。
   - 10s/25p：耗时 `-4.8%`，25/25 均更快；All 三项质量点估计改善，confirmation 的 PSNR 和 LPIPS paired 95% CI 支持改善。

3. `k_reuses_q_layout`
   - 仅构造 Q 侧 reblock 布局，K 侧复用 Q 侧在同一原始 video-token 索引空间中的最终置换；V 跟随最终 K 布局。
   - 5s/50p：耗时 `-3.4%`，All 三项点估计小幅改善，但新增 25 prompts 的三项点估计均略差。
   - 10s/25p：耗时 `-4.9%`，但 PSNR `-0.345 dB`、SSIM `-0.0116`、LPIPS `+0.0062`；SSIM 退化的 paired 95% CI 不跨 0。因此不再列为质量保持型优先候选，只在明确接受质量风险的速度场景保留。

后续组合实验优先单列 `landmarks64 + q_reuses_k_layout`。`landmarks64 + k_reuses_q_layout`
不进入首轮组合，除非目标明确转为速度优先并接受 10s 质量退化风险。所有组合继续使用相同 prompts、
seed、Dense 参考、Top-K 预算和尾部保护口径，以检查交互，不能由单轴结果直接推断组合收益。
Q 复用 K 与 K 复用 Q 互斥，不组成同一个联合变体。
